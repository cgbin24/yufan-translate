翻译服务

内置 MyMemory 免费翻译。默认每天 5,000 字符匿名额度。 填写一个邮箱可将额度提升到每天 50,000 字符（MyMemory 不会发送邮件，仅作为配额桶 ID）。

翻译时，你输入或划选的文本会发送给 MyMemory；查单词时还会另外请求 Free Dictionary API（英文词）与 必应词典 cn.bing.com（中/日/韩词，以及双语例句）。 三者均不携带你的身份信息。

    自定义翻译端点

    添加多个第三方翻译服务（Google Cloud Translation、DeepL、Azure Translator、自建反代等）， 按需选用一个作为默认翻译源。未选中时使用内置 MyMemory。

    接入协议

    • 请求：POST + JSON 体 {"text":"…","source":"auto","target":"zh-CN"}； 填了密钥会附带 Authorization: Bearer <key> 请求头。
    • 响应：JSON，必须包含译文字段 translated （也接受 translation / data）； 可选 detected（识别到的语种）与 provider（来源名称）。
    • Google Cloud Translation / DeepL / Azure Translator 等官方 API 的出入参与本协议不同， 需要自建一层适配（反代）转成上述格式后再填入 URL。
    • 启用自定义端点后，划词查词将不再查询内置词典，一律按整句翻译返回。

    还没有端点，点击下方按钮添加一个

    数据存于本机（chrome.storage.local），不同步到云端。当前激活端点跨设备同步。

    使用提示

    • 在网页上划选文字即可看到翻译气泡。
    • 整页翻译：在网页上右键 → 「语翻 · 翻译此页面」。 翻译过程中右下角会出现浮层，点它的关闭按钮即可恢复原文。
    • 点击扩展图标打开的是翻译面板（输入文本翻译），设置入口在面板内。
    • 遇到 5000 字符不够用，填一个邮箱即可解锁 50000 字符/日。
    • 如需更高额度或私有化部署，配置自定义端点即可。
